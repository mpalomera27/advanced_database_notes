# Challenge 03 — SQLBolt Lessons 10–11

## Tema
Consultas con funciones de agregación sobre la tabla `employees`.

## Conceptos practicados
- `MAX`, `AVG`, `SUM`, `COUNT` — funciones de agregación
- `GROUP BY` — agrupar resultados por categoría
- `HAVING` — filtrar grupos después de la agregación
- Diferencia entre filtrar con `WHERE` (antes de agrupar) y `HAVING` (después)

## Tablas utilizadas
- `employees` (role, name, building, years_employed)
