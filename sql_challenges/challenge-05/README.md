# Challenge 05 — Set Operations

## Tema
Operaciones de conjuntos entre dos colecciones de LEGO: `my_brick_collection` y `your_brick_collection`.

## Conceptos practicados
- `UNION` — combinar resultados de dos consultas eliminando duplicados
- `UNION ALL` — combinar resultados conservando duplicados
- `MINUS` / `EXCEPT` — elementos que existen en la primera consulta pero no en la segunda
- `INTERSECT` — elementos que existen en ambas consultas

## Tablas utilizadas
- `my_brick_collection` (colour, shape)
- `your_brick_collection` (colour, shape)
