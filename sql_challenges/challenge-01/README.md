# Challenge 01 — SQLBolt Lessons 1–5

## Tema
Consultas SELECT fundamentales sobre la tabla `movies` y `north_american_cities`.

## Conceptos practicados
- `SELECT` básico — elegir columnas específicas o todas (`*`)
- `WHERE` con operadores numéricos (`=`, `!=`, `BETWEEN`, `IN`)
- `WHERE` con texto (`LIKE`, `%`, `NOT LIKE`)
- `DISTINCT` para eliminar duplicados
- `ORDER BY` ascendente y descendente
- `LIMIT` y `OFFSET` para paginar resultados

## Tablas utilizadas
- `movies` (id, title, director, year, length_minutes)
- `north_american_cities` (city, country, population, latitude, longitude)
