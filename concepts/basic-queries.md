# Concept name

## My understanding
Basic queries are the first type of SQL statements used to get information from a database. They allow me to select columns, view all rows, and apply simple conditions to find the data I need.

## Why it matters
This matters because basic queries are the foundation of working with databases. Without them, it is not possible to search, filter, or organize information correctly.

## Example
Using SELECT to show the title of all movies from the movies table.
