# Session – 2026-03-12

## Topics covered
- Set operations: UNION, UNION ALL, INTERSECT, MINUS
- Using DISTINCT to remove duplicates
- NOT EXISTS as an alternative to MINUS for handling NULLs
- Combining set operations to find differences between tables
- Comparing table contents using aggregation with UNION ALL

## What I understood
- UNION combines results from two queries and removes duplicates, UNION ALL keeps them
- MINUS returns rows in the first query that are not in the second
- INTERSECT returns only rows that exist in both queries
- Both queries in a set operation must have the same number and type of columns
- MINUS and INTERSECT treat NULLs as equal, but direct comparison with = does not, so NOT EXISTS needs explicit NULL handling
- You can combine multiple set operations to find symmetric differences between tables
- Using UNION ALL with aggregation is a reliable way to compare row counts between tables per group

## What is still confusing

- When to prefer NOT EXISTS over MINUS for practical use cases
