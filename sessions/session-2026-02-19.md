# Session – 2026-02-19

## Topics covered
- INNER JOIN to combine data from two related tables
- OUTER JOINs (LEFT JOIN, RIGHT JOIN, FULL JOIN) to include unmatched rows
- Using IS NULL to find records with no match in another table

## What I understood
- INNER JOIN only returns rows that have a match in both tables
- LEFT JOIN keeps all rows from the left table even if there is no match on the right
- LEFT JOIN + WHERE IS NULL can be used to find orphan records (e.g. pages with no likes)
- The ON clause defines the relationship between tables using primary/foreign keys

## What is still confusing
- When to use RIGHT JOIN vs just flipping the table order with LEFT JOIN
- Practical cases where FULL JOIN is actually needed

## Questions
