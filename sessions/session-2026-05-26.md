## What I understood

This activity showed how a database can keep history instead of only saving the newest value. The trigger records changes automatically, and the ETL uses that history to make correct reports. 

The main ticket table only shows the current state, but the history table keeps the past assignments. This is useful because a ticket can move from one agent to another. The trigger helps because it saves the old and new assignment automatically. In the data warehouse, the fact table stores daily numbers, and the dimension table gives more information about each agent.
