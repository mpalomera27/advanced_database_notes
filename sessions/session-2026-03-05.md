# Session – 2026-03-17
## Topics covered
- Window functions en SQL: DENSE_RANK(), RANK(), ROW_NUMBER()
- PARTITION BY para segmentar rankings por grupo
- Filtrado de resultados de window functions con CTEs (WITH ... AS)
- JOIN entre tablas employee y department

## What I understood
- DENSE_RANK() asigna el mismo rango a empates sin dejar huecos en la numeración
- Para filtrar sobre window functions hay que envolverlas en una CTE o subquery,
  porque WHERE no puede referenciar aliases de SELECT directamente
- PARTITION BY reinicia el ranking por cada department_id
- La diferencia clave entre las tres funciones al manejar empates:
  - DENSE_RANK: mismo rank, sin huecos (1, 2, 2, 3)
  - RANK: mismo rank, con huecos (1, 2, 2, 4)
  - ROW_NUMBER: rank único arbitrario (1, 2, 3, 4)
